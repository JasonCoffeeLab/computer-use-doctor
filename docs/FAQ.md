# 疑難排解

「查到的不是我的設定」：查看頁首的正在使用目錄。Doctor 優先採本人選擇，其次 CODEX_HOME，再次預設 `.codex`。從 Finder／Dock 開啟時，不假定能收到終端機環境；請用 App 的資料夾選擇功能。指定目錄無效不自動退回其他環境。

「切換資料夾後舊結果不見了」：這是防止跨環境誤修復。舊診斷、實測批次與本次自動修復授權已清除；先檢查新環境，再決定是否修復。

「資料夾選擇不能確認」：先取消，使用「或直接指定設定路徑」，輸入自己既有目錄的絕對路徑。開啟／取消及直接輸入已測，資料夾選擇確認在目前環境尚未完成驗收，不強迫重複點擊或猜測位置。

「實測尚未就緒」：代表依賴檢查有缺口，還沒開始點擊，不是點擊已失敗。查看缺件提示；有效配置診斷、實際工具操作、正式分發仍是不同驗收層次。

「已停用」不是「壞掉」。它表示設定明確停用該入口；Doctor 不自動推翻你的設定。現行實測用既有 node_repl 工具，舊獨立入口停用不必然使現行入口失敗。

「連接配置已核對」只代表命令、版本和檔案結構匹配。「本次操作通過」才是這次實際讀取、點擊和结果回讀成功，兩者不混用。

「找不到 standalone CLI」：在官方桌面 App 檢查自己的安裝與工具設定。本預覽不支持任意 PATH 命令；npm／Homebrew 安裝不是故障證據，但目前未驗證。不要為了通過而把不明執行檔改名成 codex。

「缺少 node_repl」或工具契約改變：先確認官方 App／Computer Use 是否可用及已啟用。不要貼入其他人的 config.toml、憑證或私有環境值。

「本次實測失敗」：查看實測階段與具體原因。初始化成功不代表 native pipe 或操作通道成功；批次不匹配、重複按鈕、未知結果都不能改成通過。不要靠重點按鈕掩蓋結果未知。

「自啟動點不了」：確認 App 放在支援的 Applications 位置，不在 iCloud／暫存內。若副本與本機版本不一致，程式保留視窗並提示，不覆蓋本機版本。

「自動修復怎麼還會停」：自動修復只在使用者確認過的來源、範圍及交易條件成立時處理；未知來源、版本改變、未完成交易、外部權限或平台拒絕都不是可盲目修復的快取問題。

回報問題可附 App 版本、macOS／晶片、官方桌面版版本、錯誤階段及已遮蔽的短訊息。不要提交整份私人診斷、auth.json、config.toml、帳號、網站內容或完整電腦畫面。
