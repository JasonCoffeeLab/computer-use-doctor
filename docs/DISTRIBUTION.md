# 免費 GitHub 分發與使用驗收

目前發布維持 Preview，不能因本機測試通過就改成穩定版。

## 現行停點

維護者已明確選擇免費在 GitHub 提供下載，不做 App Store 上架，不把付費 Apple Developer 帳號或正式簽署／公證作為交付完成條件。未正式簽署是已知分發限制。亦沒有另一台乾淨 Mac 或獨立測試帳號，這項保留未驗。不建立付費帳號、憑證、登入配置或 macOS 帳號，也不索取密碼／私鑰。

## 免費分發方式

GitHub 倉庫提供 MIT 原始碼、教學與隔離測試；Releases 提供預覽 App ZIP、來源包及 SHA256SUMS。保留舊版供回退，不以相同標籤覆蓋下載者已取得的版本。build.sh 只做本機臨時簽署，不暗示 Apple 開發者身分或已公證。

下載者對未簽署／未公證提示，只有在本人確認來源可信且檔案完整後，才可依 Apple 官方單一 App「仍要打開」方式自行決定。已損壞、已知惡意軟體或撤銷授權等告警須另查，不以關閉整個系統保護來處理。不承諾所有 Mac 無提示啟動。

官方說明：https://support.apple.com/en-us/102445

## 乾淨 Mac 的驗收

1. 用另一個帳號或乾淨 Apple Silicon Mac，從 Releases 下載並核對檔案；測 Gatekeeper 首次啟動，不關閉保護。
2. 尚未準備官方工具時，驗證首次使用提示、不生成配置、不開啟停用工具、不執行修復。
3. 由本人在官方 App 準備自己的登入和 Computer Use；確認預設或自訂目錄使用正確，沒有查另一份環境。
4. 按開始檢查，取得新批次、五次實際點擊、1 + 1、結果 2；修復後用另一個新批次驗證，不沿用結果。
5. 選擇缺件或無效設定目錄，核對清除舊結果、禁止誤修復，再恢復正常目錄重驗。
6. 由本人啟用登入項目，實際登出／登入及重開機後確認正確版本執行；只登記成功不能算通過。
7. 保留版本、環境、操作與結果，去除身份／秘密後回報。截圖品質仍需另驗，不用文字讀回代替。

本機隔離測試與模型測試不能勾掉這些真實環境項目。
