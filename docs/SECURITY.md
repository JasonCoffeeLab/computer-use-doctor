# 安全與資料範圍

本工具在本機讀取使用者自己的 Codex 設定與插件來源、快取、版本連結，以及 Chrome 原生連接描述。修復需確認本次範圍，交易有備份、雜湊、所有權與恢復檢查；不清理不相關資料、不重寫功能程式、不修改 VPN 或系統代理。

人工操作驗證會啟動使用者已安裝的 Codex CLI app-server，使用官方臨時上下文及既有 node_repl 工具。固定測試程式只定位 Doctor 自身面板；目標 App 路徑需與內置模組及 Bundle ID 匹配，不接受任意其他 App 作為測試目標。

App Server 建立上下文時可能初始化使用者既有配置中的 MCP 服務；這是官方工具上下文的啟動行為，不等於 Doctor 對其他工具發出操作命令。只應在使用者已信任自己的既有配置時執行人工實測，不以「只點自己」宣稱不會啟動其他已配置服務。

不讀取或保存 auth.json 內容、不附帶登入資料、不偽造身份或批准、不啟動模型推理回合。官方 CLI 可按其本身流程使用使用者已存在的帳號；工具本身是否連接官方服務及如何處理資料，仍受官方產品設定與政策約束，不能宣稱整條工具鏈永不連網。

收到額外平台批准請求會停止並報告，不自動批准。明確拒絕不能改用另一條路繞過。Doctor 不授權 Jarvis 管理會話、不登入網站、不操作付款或公開發布。
