# V9.0.1 公開候選版驗證與發布停點

核對日期：2026-10-08（台北）。本預覽使用獨立 Bundle ID：org.computer-use-doctor.preview.v9。這是新候選版，不沿用 Preview 1 的測試結果。

## 本次已執行

- 114 項 Python 隔離測試通過，包含既有快取／交易／恢復保護，以及自訂 CODEX_HOME、明確選擇優先、無效位置不退回、缺配置／工具提示、秘密不進入錯誤提示、臨時程序排除無關獨立入口等。
- 原生模型 smoke 通過：實測入口、面板計算、無活動批次保護、來源副本與本機副本匹配、防止覆蓋修改後目標。這是隔離模型測試，不是滑鼠操作實測。
- Apple Silicon／macOS 14 目標 App 已編譯，臨時簽署與嚴格簽署檢查通過。臨時簽署不是 Developer ID／公證。
- 本機實際介面：切入隔離缺件目錄，顯示與報告一致，清除舊診斷與授權，缺少操作工具時只做配置診斷、實測點擊 0；可恢復原目錄。沒有修改官方配置或讀取登入憑證。
- 操作實測曾一次通過，後續一次逾時、點擊 0；新臨時啟動參數初版又有鍵名語法錯誤，已核對及修正。最終修正後「開始檢查」與零候選「修復並核查全部項目」分別使用不同新批次通過：同一批次摘要中讀回五次實際點擊、算式 1 + 1、結果 2；保留歷史失敗，不宣稱所有環境全面通過。
- 新版路徑直接輸入與恢復預設已實際驗證；資料夾對話框開啟／取消已驗證，確認資料夾的完整流程尚未驗收。可用直接輸入替代，不把取消成功說成選擇成功。
- 測試期間有不相容 App 提示；已定位相關 iOS App 元資料，但提示的精確起因與 Doctor 之間關係未確認，不宣稱問題已排除，不修改其他 App。
- 公開來源限定 Sources、Resources、tests、build.sh、LICENSE 及新增通用文件，沒有納入私人 V9 的歷史文件／操作回執／工作資料。
- 交付仍採 ZIP；最終包另核對，不能沿用前一版簽署或雜湊。iCloud 展開副本的已知 Finder／資源附加資料風險不作為本機 App 已通過的證據。

## 發布方式

原始碼倉庫收納通用文件、source、tests 及 LICENSE；二進位 App ZIP 與 SHA-256 附在 GitHub Releases，標明 Pre-release。不要提交 dist、.build-cache、auth.json、config.toml 或私人診斷。

免費預覽的發布頁必須保留未簽署與相容性限制，提供 Apple 官方單一 App 使用者確認方式，不附停用整體安全保護的指令。最終操作驗收未通過時保留候選，不替換已發布下載版本。
