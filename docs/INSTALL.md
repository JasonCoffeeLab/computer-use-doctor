# 安裝與操作

## 安裝前

本工具不是獨立 Computer Use 引擎。使用者必須先在官方桌面 App 登入自己的帳號並完成 Computer Use 設定。Doctor 不索取密碼、不複製別人的登入資料、不自動修改官方工具停用開關。

公開預覽的必要條件：Apple Silicon、macOS 14+、`/usr/bin/python3` 3.9+、官方桌面版的 standalone CLI、有效且已啟用的 node_repl 設定。其他安裝方式尚未驗證。

App ZIP 與來源下載不同。一般使用者下載 App ZIP；開發者下載來源再建置。核對下載檔案 SHA-256 與 Releases 公布的值；雜湊能檢查下載一致性，不能代替可信發布者簽署。

## 初次使用

App 開啟後先顯示「使用準備與設定位置」。確認它正在使用你的設定目錄；若不對，按「選擇設定資料夾」，選自己已存在、內含 config.toml 的 Codex 目錄。此選擇只記錄在 Doctor 偏好，不改官方設定、不搬移或複製帳號資料。可按「使用環境／預設位置」取消選擇。

也可展開「或直接指定設定路徑」，輸入自己的既有資料夾絕對路徑後按「使用此路徑」。不將名稱猜成路徑；不存在、空值、相對路徑或過廣的根目錄會被拒絕，不改查其他設定。資料夾選擇可取消，取消不切換環境。

缺件時展開「實測尚未就緒：查看缺件與處理方法」。按提示在官方 App 處理後重新檢查；沒有 config.toml、解析錯誤或配置為符號連結時不做快取修復，不以舊的成功報告代替本次檢查。缺操作工具不等於已確認配置快取損壞。

解壓 App，移入系統 `/Applications` 或使用者 `Applications`。若同名 App 已存在，先退出並保留舊版備份，再由自己決定更新，不把新舊版同時用來修復同一環境。

若檔案保存在 iCloud，先將 ZIP 下載至本機再解壓；不要直接執行 iCloud 的展開 App。本次已觀察到 iCloud 展開副本附加 Finder／資源資料，使嚴格簽署檢查失敗；同一 ZIP 在獨立本機解壓後通過。

按「開始檢查」後，本機配置、快取與實際操作分開顯示。真正操作成功應有新批次識別、5 次點擊、算式和結果；只有「本機檢查通過」不等於工具已能點擊。

修復只處理已確認來源、版本及範圍的快取／連結。先核對計畫再確認；來源、內容或交易狀態改變時停止受影響的修復，不盲目覆蓋。備份及恢复在「備份與恢復」頁處理。

想持續觀察時保持 App 執行。自動檢查每 60 秒讀取環境；背景觀察不搶焦點、不做滑鼠實測。人工檢查／修復才執行自身面板測試。

「登入 Mac 後啟動」由使用者選擇。macOS 若要求允許登入項目，由本人在系統設定處理。登記成功不等於已實際驗證重新登入／重開機。

## 系統阻擋與權限

本預覽沒有 Developer ID 簽署／公證，採免費 GitHub 分發，不需要付費 Apple Developer 帳號。首次提醒不代表一定是程式故障，也不能保證一定安全。

下載者先核對本儲存庫來源與 SHA256SUMS；若本人確認信任且檔案未被改動，可先嘗試開啟，再依 Apple 官方說明，到「系統設定 → 隱私權與安全性」為這個 App 選「仍要打開」，並在後續對話框本人確認開啟。這是單一 App 的使用者決定，不是關閉整個 Gatekeeper。選項也可能因 macOS 版本或受管理裝置限制而不可用。

如果提示為「已損壞」「將損壞電腦」或惡意軟體，停止並核對下載／完整性與具體告警，不自行套用上述未簽署處理方式。不要執行解除隔離或停用系統保護的命令。

Apple 官方說明：https://support.apple.com/en-us/102445

工具若要求系統原生批准、登入或本人認證，依官方入口處理。Doctor 的檢查結果不能授予其他 App／Jarvis 的權限，也不能替使用者通過密碼或 Touch ID。
